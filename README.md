Сборка помогает настроить доступ к Discord, YouTube и другим сайтам. Для Telegram Desktop есть отдельный встроенный модуль. Устанавливать Python не нужно.

Подходящая стратегия зависит от провайдера и сети. Это независимая сборка на основе [Zapret 2](https://github.com/bol-van/zapret2).

## Что нового в 0.4.6

- **10. DNS Settings** переключает Google, Cloudflare и Quad9, возвращает автоматический DNS и восстанавливает исходные настройки выбранного адаптера.
- В Windows 11 можно включить или выключить **DNS over HTTPS**. Исправлена проверка выключения; текущий провайдер и режим HTTPS видны в главном меню.
- Сетевой адаптер выбирается автоматически; его можно сменить внутри DNS Settings. Пункты главного меню расположены по порядку: настройки — 4–10, обновления — 11–13, инструменты — 14–16.
- Все 22 Classic синхронизированы с исходной сборкой **1.10.4**. Обновлены фейки, встроенный IPSet, доменные исключения и обнаружение Happ.
- Исправлена загрузка Telegram helper из скачанного архива: ручная разблокировка DLL больше не требуется.
- Уточнены границы общего диагностического отчёта: он проверяет веб-доступ, а результат входа в игру указывается отдельно.

**С опубликованной версии 0.4.1 и более ранних нужно один раз обновиться вручную** по [инструкции ниже](#updating). Начиная с 0.4.2 следующие стабильные версии можно устанавливать через `111`.

## Быстрый старт

1. Откройте [последний релиз](https://github.com/Dunterbabochka/zapret2-next/releases/latest) и скачайте **`zapret2-next-vX.Y.Z.zip`** из **Assets**. Архив **Source code** для установки не подходит.
2. Распакуйте ZIP, например в `C:\zapret2-next`.
3. Откройте **`service.bat`** и подтвердите запрос прав администратора Windows.
4. При необходимости настройте **Game Filter** и **Discord Voice**. Для начала можно оставить исходные настройки.
5. Выберите **1. Install Service**, затем номер стратегии **general** — установка начнётся сразу. После её завершения нажмите любую клавишу, чтобы вернуться в меню.
6. Проверьте нужные сайты и приложения. Если результат не подошёл, снова выберите **1. Install Service** и другую стратегию.

Готово: Zapret работает в фоне и запускается вместе с Windows. Закрыть окно меню можно. Для просмотра состояния используйте **3. Check Status**, для отключения — **2. Remove Service**.

После установки оставьте папку сборки на месте: служба запускается из неё.

## Telegram Desktop

В `service.bat` откройте **9. Telegram → 1. Enable and connect Telegram**. В Telegram подтвердите подключение к предложенному прокси.

Модуль будет запускаться при входе в Windows. Чтобы отключить его, выберите **4. Disable proxy** в меню Telegram и выключите прокси в самом приложении. [Подробнее о Telegram](docs/TELEGRAM.md).

## Настройки DNS

В разделе **Settings** выберите **10. DNS Settings**: доступны Google, Cloudflare и Quad9, переключатель **HTTPS [off/on]**, возврат к автоматическому DNS и восстановление исходных настроек. Адаптер выбирается автоматически по основному маршруту; изменить его можно через **7. Сменить сетевой адаптер** внутри DNS Settings.

Рядом с пунктом DNS Settings показан статус основного подключения: например, **[GOOGLE | HTTPS]**, **[CL.FLARE | HTTPS OFF]** или **[AUTO]**. `AUTO` означает получение DNS от сети, `HTTPS OFF` — выбранный DNS без шифрования.

DNS меняется для выбранного адаптера, включая включённые IPv4/IPv6. Шифрование DoH доступно в Windows 11; смена DNS без шифрования — также в Windows 10 версии 2004 и новее. [Режимы HTTPS и восстановление](docs/ADVANCED.md#dns-settings).

Перед первым изменением сохраняется исходная конфигурация: пункт **6. Восстановить предыдущие настройки** возвращает её. Сохраняйте папку `runtime/dns-settings`, пока нужно восстановление. Пресеты не проверяют доступность IPv6 у провайдера: включённый протокол в Windows сам по себе её не гарантирует.

<a id="troubleshooting"></a>

## Если что-то не работает

- Проверьте **3. Check Status** в `service.bat` и попробуйте другую стратегию через **1. Install Service**.
- На время проверки закройте другие сборки Zapret, VPN и сторонние прокси.
- Откройте **14. Run Diagnostics → 1. Quick check**, чтобы проверить компоненты и окружение.
- Если ни одна стратегия не помогла, подготовьте отчёт по инструкции ниже.

<a id="help-project"></a>

## Помощь проекту

Не подошла ни одна стратегия? Ваш результат поможет улучшить сборку:

1. Откройте **`service.bat` → 14. Run Diagnostics → 2. Create support report (automatic)**.
2. Укажите **провайдера** и, желательно, **область или город** — это необязательно. Подтвердите начало проверки.
3. Дождитесь окончания: проверка сама переберёт стратегии и подготовит ZIP в **`runtime\support-reports`**. Прежнее состояние службы будет восстановлено.
4. [Создайте обращение на GitHub](https://github.com/Dunterbabochka/zapret2-next/issues/new?template=strategy-report.yml), приложите **созданный ZIP** и кратко напишите, что не работает. Провайдер обязателен, область или город — по желанию.

Отчёт для отправки включает безопасный журнал последних пяти сессий; подробные локальные логи остаются отдельно. Ничего не отправляется без вашего участия. [Что проверяет диагностика](docs/SUPPORT.md).

При ошибке обновления или команды меню достаточно **14. Run Diagnostics → 5. Create logs archive**. ZIP появится в **`runtime\logs\exports`**: приложите его к обращению в GitHub или Discord. В безопасном журнале нет секретов Telegram, токенов, IP/MAC, личных путей, содержимого списков и произвольного ввода.

Дополнительно можно связаться в **Discord: `codeinoslav1488`**.

Если сборка помогла, поддержите проект **[⭐ звездой](https://github.com/Dunterbabochka/zapret2-next)** — это помогает другим найти его.

## Частые вопросы

<details>
<summary><strong>Какую стратегию выбрать?</strong></summary>

Начните с `general`, затем попробуйте остальные через **1. Install Service**. Универсальной стратегии для всех сетей нет. Для расширенного подбора доступен **14. Run Diagnostics → 3. Compatibility Wizard (advanced)**.

В установке и Run Tests используется один порядок: `ALT1 (ALT)`, `ALT2`…`ALT13`, `EXP`, `general`, затем FAKE TLS, SIMPLE FAKE и NEXT. `ALT1 (ALT)` — прежняя стратегия `ALT`; имена её файлов сохранены. Номера 1–13 соответствуют номерам ALT, `EXP` — 14, `general` — 15.

**15. Run Tests** показывает результаты коротких HTTP/TLS-проверок; ping учитывается отдельно. Standard проверяет HTTP-заголовки, DPI — короткую передачу данных. Даже зелёный результат не подтверждает воспроизведение видео или устойчивость соединения в течение вечера — проверьте это в самом приложении. После завершения тестов или ошибки любая клавиша закрывает окно тестов.

</details>

<details>
<summary><strong>Нужно ли открывать service.bat после каждой перезагрузки?</strong></summary>

После установки службы — нет. Она запускается автоматически. Меню нужно для смены стратегии, настроек и диагностики.

</details>

<details>
<summary><strong>Антивирус реагирует на WinDivert — что делать?</strong></summary>

WinDivert — компонент обработки сетевого трафика, который некоторые антивирусы определяют как RiskTool/HackTool. Скачивайте сборку из [Releases этого проекта](https://github.com/Dunterbabochka/zapret2-next/releases). При срабатывании проверьте название обнаруженного файла и результат **Quick check**.

</details>

<a id="updating"></a>

<details>
<summary><strong>Как обновиться?</strong></summary>

**В 0.4.2 и новее:** откройте `service.bat`. При обнаружении стабильного релиза появится предложение ввести **111**. Пункт **13. Check for Updates** повторяет проверку вручную, пункт **6. Auto-Update Check** управляет автоматической проверкой. Обновление сохраняет настройки и списки в прежней папке, восстанавливает прежнее состояние запуска и открывает новое меню. [Подробнее об обновлении и восстановлении](docs/UPDATING.md).

**Если добавляли свои пресеты:** перед обновлением отдельно сохраните свои шаблоны и лаунчеры, затем верните их в новую версию. Папки `presets` и `strategies` заменяются файлами релиза. Если служба использует локальный пресет, сначала выберите штатную стратегию через **1. Install Service**.

**С опубликованной 0.4.1 и более ранних:** удалите старую службу через **2. Remove Service**. Если включён Telegram-модуль, отключите его через **9. Telegram → 4. Disable proxy**. Распакуйте актуальный релиз в отдельную папку и установите службу из нового `service.bat`; прежнюю папку сохраните, пока не перенесёте свои списки и нужные настройки. Не копируйте старый `runtime` целиком поверх новой установки.

</details>
