# Автоматический отчёт

Откройте **service.bat → 13. Run Diagnostics → 2. Create support report (automatic)**.

Укажите провайдера и, по желанию, область или город. После одного подтверждения программа проверит окружение, временно остановит службу этой папки и сравнит доступность адресов без Zapret и со всеми публичными стратегиями. Ручные действия в Discord не нужны. При большом числе недоступных адресов проверка может занять до 30 минут; ход проверки отображается в окне. Для штатной отмены используйте Ctrl+C и дождитесь восстановления службы.

## Что проверяется

- Права администратора, необходимые файлы и закреплённые SHA256 компонентов.
- Служба Windows BFE, драйвер WinDivert, состояние службы Zapret и наличие IPSet.
- Признаки других сборок Zapret, конфликтующих программ, VPN и прокси.
- DNS/TLS/HTTP-доступность адресов из общего набора Compatibility Wizard: контрольный проход без Zapret, все публичные стратегии с `IPSet=loaded`, `Game=off`, `Voice=off`.
- Дополнительный проход неудачных стратегий с `IPSet=any`, который используется только для диагностики и не сохраняется в настройки.

Служба должна принадлежать этой папке. Другие службы, ручные процессы и активные конфликтующие программы автоматически не останавливаются: вместо этого сохраняется отчёт о препятствии. Отсутствие PktMon не мешает этой проверке. VPN, прокси, DNS и системные настройки не изменяются.

Ответ HTTP показывает сетевую доступность адреса, но не гарантирует обход блокировки. Звонки Discord, демонстрация экрана и воспроизведение видео остаются непроверенными. Автоматический режим не устанавливает найденную стратегию и не заявляет подтверждённую совместимость провайдера.

## Где результат

Готовый ZIP для обращения: **`runtime/support-reports/support-<дата>-<id>.zip`**. Его путь выводится после проверки. ZIP содержит только:

- `REPORT.txt` — краткий итог;
- `results.json` — версии, режимы, провайдер/регион, результаты окружения и сетевых проверок, состояние восстановления;
- `web-results.csv` — таблицу проверенных целей, стратегий, режимов, HTTP/curl-кодов и длительности.

Архив создаётся из разрешённого набора полей. В нём нет IP/MAC-адресов, PID, абсолютных путей, командных строк, пользовательских списков, подробных логов, секретов и захватов пакетов. Указанные вами провайдер и регион входят в отчёт.

Подробности проверки сохраняются рядом, в `support-<дата>-<id>/local`; эта папка не включается в ZIP. При отсутствии сети, ошибке отдельной стратегии, отмене или препятствии сохраняется частичный отчёт. Если папка недоступна для записи или закончилось место, ZIP может не создаться.

При штатном завершении, отмене и исключениях тестовые процессы останавливаются, а прежняя служба запускается обратно, если работала до проверки. При невозможности восстановления появляется сообщение и код `ServiceRestoreFailed` в отчёте. Принудительное завершение процесса или выключение компьютера не позволяет выполнить восстановление: в таком случае проверьте **3. Check Status** в `service.bat`.

## Как отправить

[Создайте обращение](https://github.com/Dunterbabochka/zapret2-next/issues/new?template=strategy-report.yml), приложите созданный ZIP и кратко опишите проблему. Провайдер обязателен, область или город — необязательны, но помогают сопоставлять результаты. Дополнительный контакт в Discord: `codeinoslav1488`.

Никакие отчёты автоматически не отправляются.

## Расширенная диагностика

Compatibility Wizard и отдельная диагностика Discord Voice сохранены в пунктах 3 и 4 меню диагностики. Они требуют ручных проверок и создают подробные локальные архивы другого формата. Такие архивы могут содержать сетевые адреса, пути и debug-логи; перед передачей проверьте их содержимое. Для обычного обращения используйте ZIP автоматического режима из пункта 2. Подробнее: [расширенное руководство](ADVANCED.md).
