# Classic: перенос локальной сборки 1.10.3

Каталог содержит все 22 варианта из локальной Windows-сборки 1.10.3 и два
самостоятельных пресета NEXT. Classic доступны в меню, лаунчерах, Run Tests,
Compatibility Wizard и автоматическом отчёте. NEXT SAFE/BALANCED сохраняют
собственные параметры. Результаты реальной работы по провайдерам заносятся
отдельно в COMPATIBILITY.md.

Classic воспроизводят исходные группы фейков, повторы, точки разбиения,
перекрытия, отдельные правила Google/Discord, игровые действия и ограничения
числа пакетов средствами Lua Zapret 2. Cutoff `nN` переносится в исключающий диапазон `<nN`. В частности, general использует
перекрытие 568 и 4pda, ALT2 — 652, ALT6 — 681, ALT7 — 679; badseq переносится
в tcp_seq/tcp_ack, ts — в tcp_ts, altorder=1 — в next_hostfakesplit.
multidisorder использует функцию multidisorder_legacy с исходным порядком.
Для FAKE TLS AUTO сохраняется клонирование ClientHello (`!`).

Штатные библиотеки движка не изменяются. Правила перевода сверены с
[описанием миграции Zapret 2](https://github.com/bol-van/zapret2/blob/master/docs/readme.md)
и локальными zapret-antidpi.lua/zapret-lib.lua. Бинарные фейки исходной сборки
закреплены в SHA256SUMS.txt. Хеши 22 исходных bat-файлов для сопровождающих
записаны в packaging/classic-reference.json. Воспроизводимый импорт:

```powershell
python packaging/import-flowseal.py --source 'D:\path\to\reference'
```

Это адаптация для другого движка. Дамп пакетов и проверка в сети провайдера
нужны для подтверждения сетевой эквивалентности. Выбор UDP-фейков остаётся
независимой настройкой: current сохраняет прежний фейк NEXT; исходный
ACTIVE_DISCORD соответствует steam, ACTIVE_GAME — dbank-v2. Для сравнения
с исходной сборкой выберите эти профили и Voice=compatible.

В ALT5 сохранён широкий IPv4 TCP-профиль syndata/multidisorder. Он может
затрагивать больше соединений, чем остальные варианты. Доменные исключения
NEXT применяются и к этому профилю. На всех остальных Classic исключения
действуют в обычных и IPSet-правилах. ALT5 отсутствует отдельное IPSet TCP
правило, как в исходнике. Стандартная защита Discord/STUN от игрового fallback
и переключатели Voice/Game сохраняются.

## Новые настройки

В Game Filter пункты 4 и 5 задают независимые TCP/UDP-порты, например
`1024-1934,1936-65535` и `27015,30000-30100`. Диапазоны проверяются, сохраняются
в utils/game_tcp.ports и utils/game_udp.ports и переносятся обновлятором.
Off сохраняет значения для следующего включения. Изменения применяются через
обычный механизм проверки конфигурации и подтверждения перезапуска службы.

UDP Fake Profiles показывает все подходящие `.bin` из bin/fake и lists/fakes,
их SHA256 и отдельные номера для Discord/Game. Выбранные байты копируются
в lists/fakes под именем полного хеша, затем проверяются при каждом рендеринге.
Файл не перезаписывает встроенный фейк и переживает обновление. Для добавления
своего фейка поместите `.bin` размером 1–65535 байт в lists/fakes и выберите его
в меню. Пользовательские имена и хеши не попадают в отправляемый журнал.
Релизная сборка исключает личные фейки и сбрасывает настройки на штатные.

## DPI-тест

Run Tests → DPI отправляет 64 КиБ случайных данных POST-запросом и измеряет
объёмы upload/download и время для HTTP/1.1, TLS 1.2 и TLS 1.3. Для проверки
используется IPSet=any в отдельном временном конфиге; содержимое IPSet и
постоянные настройки не изменяются. Both применяет этот режим ко всему проходу.
UNSUPPORTED не считается неисправной стратегией, DNS_ERROR и TLS_ERROR
показываются отдельно. LIKELY_BLOCKED означает возможное зависание/обрыв
передачи после 16 КиБ; это эвристика, а не доказательство DPI.

CSV содержит UploadedBytes, DownloadedBytes, DurationMs и Status. Собственный
проверочный URL и объём задаются через `-DpiHost https://host/path -DpiBytes 65536`.
Используйте URL, принимающий POST и возвращающий тело ответа. Запрос HEAD к
обычному сайту не заменяет эту проверку. Сетевой тест запускается пользователем.

Quick check и preflight используют общие проверки AdGuard, Killer, Intel
Connectivity, Check Point, SmartByte, OneDrive, системного DoH и записей
YouTube в hosts. Они дают подсказки, не изменяя систему. Наличие программы
само по себе не доказывает конфликт; отсутствие системного DoH ничего не
говорит о настройках браузера.
